This is a small mod manager which uses a structured folder system to organize your mods. The folder structure is similar to the JASM Modmanager. 

Where to add the mods:
Drop the mods you want to manage inside the right folder e.g. Citlali mods inside the characters>citlali folder.                               Your mods should no be in a path looking something like this:          ...Mods>Characters>Citlali>Mod1, Mod2, etc
